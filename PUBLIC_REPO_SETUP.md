#### **One-Command Install:**
```bash
# Mac/Linux
curl -sSL https://raw.githubusercontent.com/tammawanmufti/roblox-teleport-portal/main/install-plugin.sh | bash

# Windows PowerShell
iwr -useb https://raw.githubusercontent.com/tammawanmufti/roblox-teleport-portal/main/install-plugin.bat | iex
```

#### **Manual Install:**
```bash
# Clone to Plugins directory
cd "~/Library/Application Support/Roblox/Plugins/"
git clone https://github.com/tammawanmufti/roblox-teleport-portal.git TeleportSystem
```
